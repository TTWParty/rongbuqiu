# 绒布球生图 (rongbuqiu) v1.2.13

面向 **SillyTavern（酒馆）** 的 NovelAI 插画、AI 分镜与正文漫画扩展，兼容主流 SillyTavern 版本（手机端与电脑端均已适配）。

## 主要特性

- **多种接入与官方 V5 格式对齐**：支持 RBQ 接口、NovelAI 官方账号及自定义中转地址，全面采用 NovelAI V5 官方 `multipart/form-data` 请求格式（纯文生图与垫图 / 蒙版 / Vibe / 参考图分块），并支持无感代理回退。
- **三种出图方式**：
  - **标签触发**：监听回复中的图像标签（支持自定义标记与正则）生成插画卡片。
  - **AI 自动分镜**：由 LLM 阅读剧情并输出分镜与提示词，自带第一人称 / 第三人称官方视角规则包，支持工具调用、无工具 JSON 回退、前置指令与尾部引导。
  - **AI 正文漫画**：将当前楼层剧情改编为多页日漫 / 条漫分格（支持 AI 自由切格与经典几何版式），支持 V5 原生绘字、前端高清矢量排版层（免重画改词与拖动微调）及纯画面模式。
- **自由创作工作台 2.3（插画 / 漫画制片 / 角色工坊）**：100% 独立于当前聊天的三大创作专区（电脑端工作室首栏、`Ctrl+Shift+B`、聊天底栏及手机端悬浮球一键直达），内置 3.68 万 Danbooru+NAI 双语完整懒加载词库（12 分区浏览、画师/角色/作品过滤、一键 `-2::` 负向排除）、V5 Medium 自动隐藏无效负面栏、胶囊权重与语法体检、2D 多角色站位坐标与互动预设、NAI 原图 PNG（含 `stealth_pngcomp` 隐写）拖入扒词复刻、角色工坊 2.1（1.48 万官方角色名补全、衣柜触发词与服装库双向联动、画板定种与仅看定妆筛选）、自由导演要求扩写、画笔蒙版羽化无损局部重绘（Inpaint）/ 垫图（img2img）/ 四周扩图（Outpaint）/ 多版本 AB 卷帘对比、零 LLM 空白分格建页、分格比例拖拽与单格精修、双页右起 / 条漫阅读模式，以及长条漫 PNG / `.zip` / `.cbz` 电子书打包导出与后台挂机生图防淘汰保护。
- **角色库与换装记忆**：自动建档与角色外貌 / 服装持久化、锁定衣柜换装防回弹，支持多楼层角色一致性。
- **桌面端与移动端专属体验**：
  - 手机端支持自动挂边的摸鱼悬浮球（猫咪 / 小孩 / 极简三款样式）、快捷面板一键切换出图方式、失败卡片一键诊断修复与看图器直达 AI 调整。
  - 桌面端（`>= 901px` 且精确指针）支持聊天框内嵌大图卡片、独立工作室（Studio）、停靠侧栏、钉住对比窗、命令面板（`Ctrl+Shift+K`）与看图器滚轮缩放 / 快捷键浏览。
- **全量备份与从 RBQ 导入**：支持一键导入原有 RBQ 配置、角色与图片历史，并支持导出 / 恢复包含设置、画风预设、分镜规则、角色库、服装库与创作工作台工程的备份文件。

## 安装方法

### 方式一：通过 SillyTavern 扩展管理安装（推荐）

1. 打开 SillyTavern → **扩展（Extensions）** → **安装扩展（Install Extension）**。
2. 粘贴仓库地址：
   ```
   https://github.com/TTWParty/rongbuqiu
   ```
3. 安装完成后刷新页面，按首次设置向导完成配置即可。

### 方式二：手动安装发布包

下载发布包 `rongbuqiu-1.2.13.zip`，解压至 SillyTavern 的 `data/<你的用户名>/extensions/` 目录，确保目录结构为：
`extensions/rongbuqiu/manifest.json`、`extensions/rongbuqiu/dist/boot.js` 等，随后刷新 SillyTavern。

## 快捷使用

1. **首次配置**：页面就绪后会自动弹出 3 步新手设置向导（或点击屏幕侧边的悬浮球进入控制台 / 工作室 › **重新看引导**），可一站式完成画图 Key 检查与线路切换、玩法与出图时机选择、分镜 AI 测试及防拒答保护设置。
2. **切换出图方式**：在悬浮球快捷面板、底部状态条或设置顶部随时切换 **标签 / AI 分镜 / 漫画**。
3. **点击查看大图**：在聊天卡片、测试出图预览、角色画风缩略图或历史记录中点击图片即可打开看图器，支持缩放、版本切换与原图导出。
4. **版本检查与更新**：打开控制台或桌面工作室会自动静默检查更新，也可在 **设置 › 通用 › 版本与更新** 中手动检查并一键升级。
5. **数据备份**：重要聊天与角色库建议定期在 **设置 › 备份与导入** 中导出 JSON 备份文件。
